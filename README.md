# John Webber photography lookbook

Bilingual English/Chinese client photography proposal, with visual references, five core scenarios, optional family ideas and a downloadable photo shortlist.

## Hosting

GitHub Pages: deploy from the `main` branch, repository root.

`index.html` is self-contained, with styles, scripts and reference images embedded. No build or external runtime is required.

## Reference images

Photography credits and source-gallery links appear throughout the lookbook. Third-party photographs remain the property of their respective photographers and serve as creative references, not assets for John's advertising. No blanket license is granted for those photographs.

The repository does not contain the research archive, source conversation PDF, or John's business-card image.
